2️⃣ Запустить Evolution API (WhatsApp):

docker run -d \
  --name evolution-api \
  --restart unless-stopped \
  -p 8080:8080 \
  -e AUTHENTICATION_API_KEY="evolution-key-2026" \
  evoapicloud/evolution-api:latest

3️⃣ Запустить Redis:

docker run -d \
  --name redis \
  --restart unless-stopped \
  -p 6379:6379 \
  redis:alpine

4️⃣ Проверить:

docker ps

Должны быть 2 контейнера:
  - evolution-api (порт 8080)
  - redis (порт 6379)
