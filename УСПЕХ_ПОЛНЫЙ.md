```bash
  -H "apikey: evolution-key-2026" \

```

### 4. Настроить webhook для каждого instance:

```bash
curl -X PUT http://188.241.217.76:8080/webhook/set/whatsapp-1 \
  -H "apikey: evolution-key-2026" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "http://188.241.217.76:3000/api/v1/whatsapp/webhook",
    "webhook_by_events": false,
    "enabled": true,
    "events": ["MESSAGES_UPSERT"]
  }'
```

Повторить для whatsapp-2, whatsapp-3, whatsapp-4.
