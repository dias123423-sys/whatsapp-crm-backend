# Запуск системы

---

## Вариант 1 — Локально (для разработки)

### Шаг 1: Запустить PostgreSQL и Redis через Docker

```bash
cd project
docker compose up -d postgres redis
```

Подождать 10 секунд.

### Шаг 2: Backend

```bash
cd project/backend
npm install
npx prisma generate
npx prisma migrate deploy
npx ts-node prisma/seed.ts
npm run start:dev
```

✅ Backend на: http://localhost:3001/api  
✅ Swagger docs: http://localhost:3001/api/docs

### Шаг 3: Админка

```bash
cd project/apps/admin
npm install
npm run dev
```

✅ Админка на: http://localhost:3000

### Шаг 4: Панель оператора

```bash
cd project/apps/operator
npm install
npm run dev
```

✅ Оператор на: http://localhost:3002

### Шаг 5: Evolution API (опционально)

```bash
cd project
docker compose up -d evolution-api
```

✅ Evolution API: http://localhost:8080

## ENV файлы — что где

```
backend/.env                ← локальная разработка (localhost хосты)
backend/.env.production     ← Docker (postgres/redis хосты)
apps/admin/.env.local       ← локальная разработка
apps/admin/.env             ← Docker build (VITE_API_URL=/api)
apps/operator/.env.local    ← локальная разработка
apps/operator/.env          ← Docker build
```

## Команды управления на сервере

```bash
# Посмотреть статус
docker compose ps

# Логи backend
docker compose logs -f backend

# Логи Evolution API
docker compose logs -f evolution-api

# Перезапустить backend
docker compose restart backend

# Обновить после git pull
sudo bash deploy/update.sh

# Остановить всё
docker compose down
```

## Подключение WhatsApp номера

1. Войти в Админку → **WhatsApp**
2. Нажать **Добавить номер** → ввести `whatsapp-1`
3. Нажать **QR-код** на карточке
4. Открыть WhatsApp на телефоне → **Настройки → Связанные устройства → Привязать**
5. Отсканировать QR
6. Статус станет **ONLINE**
