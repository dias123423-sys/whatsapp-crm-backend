## ⚠️ Evolution API - ПРОБЛЕМА

Evolution API не запускается из-за:
1. Docker образ требует DATABASE_PROVIDER но не принимает значения
2. Сборка из исходников падает с ошибками esbuild
3. Требует свою собственную Prisma схему (конфликт с нашей БД)

### Решения:

#### Вариант 1: Использовать готовый Docker образ (рекомендуется)
```bash
ssh root@188.241.217.76

# Остановить проблемный контейнер
D=docker && $D stop evolution-api && $D rm evolution-api

# Запустить с MongoDB (проще чем PostgreSQL)
$D run -d \
  --name evolution-api \
  --restart unless-stopped \
  -p 8080:8080 \
  -e AUTHENTICATION_API_KEY=evolution-key-2026 \
  -e DATABASE_ENABLED=false \
  -e REDIS_URI=redis://localhost:6379 \
  atendai/evolution-api:v2 или другой стабильный образ
```

#### Вариант 2: Использовать альтернативу
- **whatsapp-web.js** - более простая библиотека
- **Baileys** - легковесная альтернатива
- **WPPConnect** - русскоязычное сообщество

#### Вариант 3: Интегрировать WhatsApp напрямую в Backend
Добавить whatsapp-web.js в наш NestJS backend напрямую.
