## ✅ Что уже работает на VPS

- Evolution API: http://188.241.217.76:8080
- PostgreSQL (Neon): подключена
- Webhook: настроен и готов принимать сообщения
- WA инстансы: WA1, WA2, WA3, WA4 созданы

## 📱 Как подключить WhatsApp

### 1. Открой админку
```
https://callcenter-admin-omega.vercel.app
```

**Логин:** `admin@callcenter.kz`  
**Пароль:** (смотри в телеграмме или спроси)

### 2. Перейди в раздел WhatsApp
В боковом меню → **WhatsApp**

### 3. Получи QR коды
Нажми кнопку **"Получить QR-код"** для каждого:
- WhatsApp 1 (WA1)
- WhatsApp 2 (WA2)
- WhatsApp 3 (WA3)
- WhatsApp 4 (WA4)

### 4. Сканируй QR из WhatsApp
На рабочем телефоне:
1. Открой WhatsApp
2. Settings → Linked Devices
3. Link a Device
4. Сканируй каждый QR код

### 5. Проверка работы
После подключения:
1. Отправь тестовое сообщение на один из WA номеров
2. В админке → **Лиды** должен появиться новый лид
3. Статус WhatsApp изменится на **ONLINE**

## ⚠️ Если что-то не работает

### Webhook не принимает сообщения
Если сообщения приходят, но лиды не создаются:

```bash
ssh -i ~/.ssh/vps_callcenter root@188.241.217.76
docker logs cc_backend -f | grep "📱"
```

Должны появляться строки вида:
```
📱 WA1 | 77012345678 | Имя | "текст сообщения"
✅ Created: 77012345678
```

### WhatsApp не подключается
1. Проверь что Evolution API работает:
   ```
   curl http://188.241.217.76:8080
   ```
   Должно вернуть JSON с версией

2. Получи новый QR:
   ```bash
   API="429683C4C977415CAAFCCE10F7D57E11"
   curl -H "apikey: $API" http://188.241.217.76:8080/instance/connect/WA1
   ```

### Backend упал
```bash
ssh -i ~/.ssh/vps_callcenter root@188.241.217.76
cd /opt/callcenter/project
docker compose restart cc_backend
docker logs cc_backend
```
